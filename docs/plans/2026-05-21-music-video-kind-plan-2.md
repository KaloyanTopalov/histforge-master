# Plan 2 — Magnific integration + render (silent audio)

## Overview

Take the music-video kind from "stubs walk end-to-end with marker artifacts" (Plan 1) to "operator creates a music video, an MV3 extension drives Magnific's image-gen + image-to-video UIs from the operator's signed-in Chrome profile, and a real `final.mp4` lands with looped real clip + silent audio." Suno-side stubs (`generate_music`, `download_music`) stay in place; their swap to real Suno integration is Plan 3.

The shape is set by [ADR-0011](../adr/0011-video-kind-discriminator.md) (kind discriminator), [ADR-0012](../adr/0012-hitl-via-extension-no-timeout.md) (per-task `no_timeout` instead of a new `videos.status` value), and the [Plan-split handoff](../handoffs/2026-05-20-music-video-kind-plan.md). The vertical-slice rule from the handoff: each phase ends at a state the operator can observe — Phase 2.1 ends at a webhook smoke test + a music-video walk through stubs that no longer crashes the orchestrator; Phase 2.2 ends at an extension that polls and logs "no work"; Phase 2.3 ends at a real `loop_image.png` + `thumbnail.jpg` on disk (steps 2/6 still stubs); Phase 2.4 ends at a real `final.mp4` (silent audio).
